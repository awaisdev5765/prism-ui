# Changelog

## 0.1.0

- Initial release.
- `PrismSettingsPage` — adaptive settings screen with optional search filter
  and centered wide-window layout.
- `PrismSettingsSection` — titled grouped-card sections.
- Tiles: `PrismActionTile`, `PrismSwitchTile`, `PrismCheckboxTile`,
  `PrismSliderTile`, `PrismDropdownTile<T>`.
- `PrismSettingsController` — key-based values with `onChanged` persistence
  hook and bulk `setAll`.
